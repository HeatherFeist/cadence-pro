# Cadence

An app that helps people read aloud with confidence.

Upload a document or paste text you want to practice reading. Cadence reads the
opening lines aloud to set the tone and pace, then you record yourself reading
along a pacing highlighter you can adjust, pause, and reposition. Afterward,
Cadence listens back to what you actually said, compares it against the real
text, and plays back — in a clear voice — exactly how the words or lines you
stumbled on should sound.

## Status

Just getting started. See `docs/PLAN.md` for the current shape of the project.

## Values this project holds itself to

- **Free and honest first.** Prefer free, built-in browser capabilities
  (speech recognition, text-to-speech) over locking the project into a paid
  vendor contract before it has ever earned a dollar.
- **Privacy-respecting where it matters.** Be upfront about what leaves the
  device and what doesn't, rather than letting a convenient default quietly
  decide that.
- **Real feedback, not overpromised feedback.** Ship what genuinely works
  (word accuracy, pacing, skipped words) before claiming things that are
  still hard, unsolved problems in speech research (deep prosody/emotion
  coaching).
